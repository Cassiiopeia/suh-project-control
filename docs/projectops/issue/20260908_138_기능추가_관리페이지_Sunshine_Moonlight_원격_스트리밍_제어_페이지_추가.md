📝 현재 문제점
---

- AI 서버(Windows)에는 Sunshine 스트리밍 호스트가 서비스로 상시 구동 중이며, 외부에서 Moonlight로 원격 접속해 사용한다.
- 새 기기를 페어링하려면 서버 화면의 Windows 알림 또는 Sunshine 웹 UI(localhost 전용)에서 PIN을 입력해야 하는데, 서버가 원격지에 있어 화면을 볼 수 없으면 페어링이 불가능하다.
- 스트리밍 세션이 남아 BUSY 상태로 굳거나 서비스가 죽어도 관리 대시보드에서 확인할 방법이 없고, 페어링된 기기 목록(중복 등록 포함)도 정리할 수 없다.
- 반드시 켜져 있어야 하는 서비스인데도 기존 관리 페이지(팰월드, Ollama)와 달리 상태 확인과 제어 수단이 전혀 없다.

🛠️ 해결 방안 / 제안 기능
---

- 관리 허브에 "Sunshine 관리" 페이지(`/admin/sunshine`)를 추가한다.
- 상태 카드: Sunshine 서비스 상태, 스트림 상태(FREE/BUSY)와 실행 중인 앱, 외부 접속 주소를 표시하고 서비스 시작/중지/재시작과 실행 중 세션 강제 종료를 제공한다.
- PIN 페어링 카드: Moonlight가 표시하는 PIN과 기기 이름을 입력해 웹에서 바로 페어링을 승인한다.
- 페어링된 기기 카드: 등록된 기기 목록을 보여주고 개별 해제를 지원한다.
- 로그 카드: Sunshine 로그 tail을 자동 새로고침으로 표시한다.
- 상태를 바꾸는 모든 동작은 감사로그에 기록한다.

⚙️ 작업 내용
---

- Sunshine 웹 API(localhost:47990) 연동 서비스 계층과 설정(자격증명은 환경 파일에서 로드) 추가
- 상태 조회, PIN 승인, 기기 해제, 세션 종료, 서비스 제어, 로그 조회 API 라우터 추가
- 관리 페이지 템플릿, 사이드바 메뉴, 프론트 스크립트 추가
- 감사로그 카테고리와 액션 라벨 추가
- 라우터, 서비스 단위 테스트 작성
- 서버 환경 파일에 Sunshine 자격증명 등록(배포 후 1회)
