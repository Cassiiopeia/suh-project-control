# 관리 페이지 레이아웃 개편 - 게임 로그 우선 표시 및 플레이어 상시 노출

## 개요

팰월드 관리 페이지에 들어가면 설정 탭이 기본이라 정작 자주 보는 게임 로그는 스크롤+클릭이 필요했고, 접속 중인 플레이어는 별도 탭에 숨어 있었다. 이번 개편으로 **진입 즉시 서버 상태와 게임 로그가 바로 보이고**, 접속자가 있으면 상태 카드 안에 플레이어 목록이 자동으로 나타난다. 함께 배포되는 PR(#80)에 로그 뷰어 검색 버그 수정(#77), 실행 중 설정 저장(#78), 업데이트 UI 정리(#79)가 포함된다.

## 변경 사항

### 레이아웃
- `templates/admin/palworld.html`: 페이지 순서를 **서버 상태 → 탭(로그✓·설정·백업) → 월드·서버 정보 → 게임 접속 방법**으로 재배치. 플레이어 탭 제거, 플레이어 테이블(7컬럼)을 서버 상태 카드 안으로 이식 — 접속자 0명이면 영역 자체가 숨겨짐
- `static/js/palworld.js`: 로그 기본 소스를 **게임 로그(PalServer 원본)**로 변경(소스 순서: 게임 로그 → 이벤트 → 감사 → 업데이트 → 오류 → 시스템), `renderPlayers()`가 접속자 유무에 따라 플레이어 영역 표시/숨김

### 원칙
- daisyUI native 컴포넌트만 사용, 커스텀 CSS 추가 없음 — 다크/라이트 테마 토큰 유지
