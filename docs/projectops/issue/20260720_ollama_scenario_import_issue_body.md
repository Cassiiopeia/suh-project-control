## 개요
Ollama Structured Output 테스트 대시보드(`ollama-test.html`)에 AI가 기획한 단일 구조화된 JSON 시나리오 파일(또는 텍스트)을 원클릭으로 통째로 붙여넣고 화면 양식에 자동 파싱 분배해 입력해 주는 **"가져오기(Import)"** 기능과 현재 구성해 둔 입력 양식들을 그대로 JSON 형태로 출력받아 복사 및 아카이빙할 수 있는 **"내보내기(Export)"** 기능을 구현합니다.
또한, 외부 AI(Claude, ChatGPT 등)에 질문하여 올바른 JSON 시나리오를 설계하게 만드는 **"AI 가이드라인 복사 가이드 도구"**를 모달 내에 내장하여 사용자 경험을 극대화합니다.

## 세부 구현 요구사항
1. **AI 시나리오 설계 모달 신설 (DaisyUI v5 / Tailwind CSS v4)**
   - 요청 구성 카드 헤더 우측 상단에 `AI 시나리오 설계` 버튼 배치
   - 모달 내부에는 두 개의 탭을 탑재:
     - **탭 1 (AI 프롬프트 가이드)**: 외부 AI에 복사해 줄 지능형 프롬프트와 원클릭 복사 버튼 제공.
     - **탭 2 (JSON 가져오기/내보내기)**: 시나리오 JSON 텍스트 에어리어와 가져오기(적용) 및 현재 구성 내보내기 버튼 제공.
2. **시나리오명 동적 배지 추가**
   - AI가 주입해준 JSON에 `"title"` 값이 있으면 요청 구성 카드 헤더 옆에 `[시나리오: 병원 방문 준비]` 배지를 초록색(`badge-success`)으로 노출.
3. **지능형 JSON 정화 및 폼 바인딩 로직 (`ollama-test.js`)**
   - AI가 반환한 답변에 마크다운 백틱 코드 블록(` ```json `)이 포함되어 있어도 완벽히 감지하여 정규화 및 정화(`sanitize`).
   - JSON 검증 및 `format` 모드 연동, `temperature`, `system_prompt`, `user_prompt`, `schema_input` 필드 자동 바인딩.
   - 로드 성공 시 로컬 상태(`saveState()`)에 연동하여 영구 저장소 보존.
4. **현재 설정값 내보내기**
   - 현재 화면에 직접 수동 입력해 둔 필드값들을 시나리오 JSON 규격에 맞게 즉석 조립하여 텍스트 상자에 노출 및 클립보드에 복사할 수 있도록 유도.
