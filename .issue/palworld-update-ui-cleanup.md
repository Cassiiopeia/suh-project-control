📝 현재 문제점
---

- 서버 업데이트가 **완료된 뒤에도** steamcmd 전체 로그 패널이 서버 상태 카드 중앙에 계속 떠 있음 — 완료 상태에서는 불필요한 노이즈
- 마지막 업데이트가 언제였는지, 어떤 빌드로 됐는지 요약 정보가 없음
- 업데이트 로그는 Flask 재시작 시 사라짐 (메모리 버퍼만 존재)

🛠️ 해결 방안
---

- **진행 패널 표시 정책 변경**: 진행 중에만 표시, **완료 시 자동 숨김**(토스트 + 배지로 충분), 실패 시에는 에러 확인용으로 유지
- **마지막 업데이트 요약**: 배지 옆에 "마지막 업데이트: {시각} · 빌드 {번호}" 한 줄 표시 — 파일로 영속화해 Flask 재시작 후에도 유지
- **업데이트 로그를 로그 탭 소스로**: steamcmd 출력을 `palworld-update.log` 파일에도 기록하고 로그 뷰어에 "업데이트" 소스 추가 (감사 탭과 동일 패턴) — 과거 업데이트 이력을 언제든 조회

⚙️ 작업 내용
---

- [ ] `palworld_updater.py` — 로그 라인을 파일에도 기록, 완료 시 마지막 업데이트 정보(json) 영속화, get_state에 last_update 포함
- [ ] `palworld_config.py` — `LOG_SOURCES["update"]` 및 업데이트 로그 파일 경로
- [ ] `palworld.js` — 완료 시 패널 숨김(실패 시 유지), 마지막 업데이트 표시, 로그 소스에 "업데이트" 추가
- [ ] `palworld.html` — 마지막 업데이트 표시 요소
- [ ] Swagger logs source enum에 update 추가, 테스트
