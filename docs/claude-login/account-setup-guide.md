# Claude 로그인 인증코드: Gmail 계정 추가 안내

관리자 화면(`/admin/claude-login`)이 Gmail로 온 Claude 로그인 메일을 대신 열어 6자리 코드를 보여 줍니다.
계정은 여러 개 등록할 수 있고, 등록된 계정을 동시에 기다립니다.

## 1. 처음 한 번: 서버 설정 (관리자)

서버 `flask/.env`(GitHub Secret `FLASK_ENV_FILE`)에 앱 비밀번호 암호화용 비밀 문구를 넣습니다.

```
CLAUDE_LOGIN_ACCOUNT_SECRET=<길고 무작위인 문자열>
```

- 무작위 값 만들기: `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`
- 이 값을 바꾸거나 잃어버리면 저장된 앱 비밀번호를 풀 수 없습니다. 그때는 계정마다 앱 비밀번호를 다시 넣으면 됩니다.
- 서버를 다른 컴퓨터(Windows → Mac 등)로 옮길 때는 DB와 이 값을 함께 옮기면 그대로 동작합니다.

## 2. Gmail 앱 비밀번호 발급 (계정마다)

1. 그 Google 계정으로 로그인한 브라우저에서 **myaccount.google.com/apppasswords** 를 엽니다.
   - 보안 화면 메뉴에는 보이지 않으니 주소를 직접 입력하거나, 위쪽 검색창에 "앱 비밀번호"를 입력합니다.
   - 2단계 인증이 켜져 있어야 합니다.
2. 앱 이름에 `suh-ai-server` 처럼 알아보기 쉬운 이름을 넣고 **만들기**를 누릅니다.
3. 나온 16자리(`abcd efgh ijkl mnop`)를 복사합니다. 창을 닫으면 다시 볼 수 없습니다.
   - "사용하려는 설정을 계정에서 사용할 수 없습니다"가 나오면 회사·학교 계정 관리자가 막아 둔 경우입니다.

## 3. 관리자 화면에서 등록

1. `/admin/claude-login` → **계정 관리** 탭 → **계정 추가**
2. 표시 이름(예: 회사), Gmail 주소, 앱 비밀번호 16자리 입력 (띄어쓰기는 있어도 됨)
3. **접속 확인 후 저장** — 서버가 Gmail 접속을 시험하고, 성공하면 암호화해서 DB에 저장합니다.
   - 실패하면 저장하지 않고 이유를 보여 줍니다.

계정 관리 탭에서 이름·앱 비밀번호 수정, 사용 끄기, 접속 테스트, 삭제를 할 수 있습니다.
Gmail 주소를 바꾸려면 삭제 후 다시 추가합니다.

## 4. 코드 받기

1. **코드 받기** 탭을 열면 사용 중인 계정 전부가 메일을 기다리기 시작합니다 (최대 10분).
2. 다른 창의 Claude 로그인 화면에 그 계정 이메일을 입력합니다.
3. 메일이 온 계정 카드에 6자리 코드가 뜹니다. **코드 복사** 후 붙여 넣습니다.

- 페이지를 열기 2분 전까지 온 메일도 처리합니다.
- 10분 안에 메일이 안 오면 그 카드만 멈춥니다. **다시 기다리기**를 누르세요.
- 메일함은 읽기만 하고 읽음 표시·삭제·이동을 하지 않습니다.
- 앱 비밀번호는 화면·로그·감사로그 어디에도 다시 나오지 않습니다.
