📝 현재 문제점
---

- 팰월드 관리 페이지에 들어가면 **설정 탭이 기본 선택**이라 정작 자주 보는 게임 로그를 보려면 스크롤 + 탭 클릭이 필요
- 탭 섹션이 페이지 하단(카드 3개 아래)에 있어 로그가 한눈에 들어오지 않음
- 접속 중인 플레이어가 **별도 탭에 숨어 있어** 누가 접속해 있는지 바로 볼 수 없음

🛠️ 해결 방안 / 제안 기능
---

- **페이지 순서 재배치**: 서버 상태 카드 → 탭 섹션(위로 이동) → 월드·서버 정보 → 게임 접속 방법
- **로그 탭을 첫 탭 + 기본 선택**으로, 탭 구성은 [로그✓][설정][백업] — 플레이어 탭 제거
- **로그 기본 소스를 게임 로그(PalServer 원본)**로 변경 (소스 버튼 순서도 게임 로그 맨 앞)
- **플레이어 상시 노출**: 서버 상태 카드 안(접속자 지표 아래)에 기존 7컬럼 테이블 이식 — 접속자 있을 때만 표시, 0명이면 영역 숨김
- daisyUI native 컴포넌트만 사용, 커스텀 CSS 추가 없음 (다크/라이트 테마 토큰 유지)
