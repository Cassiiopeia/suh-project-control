### 📌 작업 개요

Flask OCR 서버의 로그를 외부에서 조회할 수 있는 REST API 엔드포인트 추가. JSON 형식(필터 지원)과 Plain Text 형식(브라우저 직접 확인) 두 가지 방식 제공

**보고서 파일**: `.report/20260213_#39_외부_서버_로그_조회_API_엔드포인트_추가.md`

### 🎯 구현 목표

- 서버에 직접 접속하지 않고도 외부(모바일, 다른 PC)에서 서버 로그를 실시간 확인
- 로그 레벨 필터(`INFO`, `ERROR`, `WARNING`)와 키워드 검색 기능 제공
- 브라우저 주소창에서 바로 텍스트로 확인할 수 있는 스트림 엔드포인트 제공

### ✅ 구현 내용

#### 1. 로그 라우터 신규 생성
- **파일**: `suh-ai-server/flask/router/log_router.py` (신규)
- **변경 내용**: `GET /logs` (JSON), `GET /logs/stream` (Plain Text) 두 개의 엔드포인트 구현
- **이유**: 장애 발생 시 빠른 원인 파악을 위해 외부 로그 조회 기능 필요

#### 2. Swagger API 스펙 추가
- **파일**: `suh-ai-server/flask/router/swagger_router.py`
- **변경 내용**: `paths`에 `/logs`, `/logs/stream` 엔드포인트 스펙 추가. `Logs` 태그로 분류
- **이유**: Swagger UI에서 로그 조회 API를 테스트할 수 있도록 문서화

#### 3. 블루프린트 등록
- **파일**: `suh-ai-server/flask/app.py`
- **변경 내용**: `log_bp` 블루프린트 import 및 `register_blueprint` 추가
- **이유**: 새로운 로그 라우터를 Flask 앱에 연결

### 🔧 주요 변경사항 상세

#### log_router.py (신규)

**`GET /logs` 엔드포인트**:
- `nssm-stderr.log` 파일을 읽어 JSON 형식으로 반환
- Query Parameters:
  - `lines`: 최근 N줄 (기본 50, 최대 500)
  - `level`: 로그 레벨 필터 (`[INFO]`, `[ERROR]`, `[WARNING]` 패턴 매칭)
  - `search`: 키워드 검색 (대소문자 무시)
- 응답에 `total_lines`, `total_log_lines`, `filters` 정보 포함

**`GET /logs/stream` 엔드포인트**:
- 최근 N줄을 `text/plain` 형식으로 반환
- 브라우저 주소창에서 바로 확인 가능
- Query Parameters: `lines` (기본 100, 최대 500)

**특이사항**:
- 로그 파일 경로는 상대 경로(`../logs/nssm-stderr.log`)로 설정하여 배포 환경에 종속되지 않음
- 파일 인코딩은 `utf-8`로 읽되, `errors='replace'`로 깨진 문자 처리
- `lines` 최대값을 500으로 제한하여 대용량 로그 파일 전체 반환 방지

#### swagger_router.py

- `/logs` 경로에 `Logs` 태그로 GET 엔드포인트 스펙 추가
- `/logs/stream` 경로에 동일한 `Logs` 태그로 GET 엔드포인트 스펙 추가
- 기존 OCR 태그와 분리되어 Swagger UI에서 별도 섹션으로 표시

#### app.py

- `from router.log_router import log_bp` import 추가
- `app.register_blueprint(log_bp)` 등록 추가

### 🧪 테스트 및 검증

- JSON 엔드포인트: `GET https://ai.suhsaechan.kr/api/flask/logs?lines=10` → Status 200, 최근 로그 10줄 정상 반환
- ERROR 필터: `GET https://ai.suhsaechan.kr/api/flask/logs?lines=5&level=ERROR` → ERROR 로그만 필터링 확인
- Stream 엔드포인트: `GET https://ai.suhsaechan.kr/api/flask/logs/stream?lines=5` → Plain Text 정상 반환
- 서비스 재기동(NSSM) 후 정상 동작 확인

### 📌 참고사항

- 현재 X-API-Key 인증은 Nginx 레벨에서 처리되므로 Flask 라우터 자체에는 별도 인증 로직 없음
- 로그 파일이 매우 커질 경우 전체 파일을 메모리에 읽는 방식이므로, 향후 로그 로테이션이나 tail 방식 최적화 고려 필요

### 🌐 API 사용법

| 용도 | URL |
|------|-----|
| JSON (필터 지원) | `GET /api/flask/logs?lines=50&level=ERROR&search=ollama` |
| Plain Text (브라우저) | `GET /api/flask/logs/stream?lines=100` |
| Swagger UI | `https://ai.suhsaechan.kr/api/flask/docs/swagger/` → Logs 태그 |
