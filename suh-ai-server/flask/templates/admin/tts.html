API 사용 가이드 외부에서 TTS API를 사용하는 방법

1. 시작하기

모든 API 요청에는 X-API-Key 헤더가 필요합니다. API 키는 서버 관리자에게 요청해 발급받으세요. 기본 주소: https://ai.suhsaechan.kr/api/flask

2. 엔진·보이스 확인

합성 전에 어떤 엔진이 실행 중인지 확인하세요 (한 번에 1개 엔진만 실행됩니다).

curl https://ai.suhsaechan.kr/api/flask/tts/engines -H "X-API-Key: {API키}"
curl https://ai.suhsaechan.kr/api/flask/tts/voices  -H "X-API-Key: {API키}"

3. 음성 합성 — POST /tts

응답은 WAV 오디오 바이트입니다. engine 생략 시 실행 중 엔진 사용, 텍스트는 500자 이하.

« curl »
curl -X POST https://ai.suhsaechan.kr/api/flask/tts \
  -H "X-API-Key: {API키}" -H "Content-Type: application/json" \
  -d '{"text": "안녕하세요", "engine": "cosyvoice", "voice": "ref_a"}' \
  --output result.wav

« Python »
import requests
resp = requests.post("https://ai.suhsaechan.kr/api/flask/tts",
    headers={"X-API-Key": "{API키}"},
    json={"text": "안녕하세요", "engine": "cosyvoice"})
open("result.wav", "wb").write(resp.content)

« JavaScript »
const resp = await fetch("https://ai.suhsaechan.kr/api/flask/tts", {
  method: "POST",
  headers: {"X-API-Key": "{API키}", "Content-Type": "application/json"},
  body: JSON.stringify({text: "안녕하세요", engine: "cosyvoice"}),
});
new Audio(URL.createObjectURL(await resp.blob())).play();

4. 보이스 클로닝 — POST /tts/voices

조용한 곳에서 10초 내외로 녹음한 WAV를 등록하면, 반환된 voice id로 그 목소리 합성이 가능합니다.

« 방법 A: 보이스 등록 후 재사용 (학습 불필요 — 등록 즉시 사용 가능) »
curl -X POST https://ai.suhsaechan.kr/api/flask/tts/voices \
  -H "X-API-Key: {API키}" \
  -F "name=내 목소리" -F "file=@my_voice.wav"
# → {"voice": {"id": "u_xxxxxxxx"}} — 이후 POST /tts의 voice에 이 id 사용

« 방법 B: 등록 없이 원샷 클로닝 (요청마다 다른 목소리 가능) »
curl -X POST https://ai.suhsaechan.kr/api/flask/tts \
  -H "X-API-Key: {API키}" \
  -F "text=안녕하세요" -F "engine=cosyvoice" -F "prompt_wav=@my_voice.wav" \
  --output result.wav

본인 또는 동의받은 사람의 목소리만 사용하세요. 타인 음성의 무단 클로닝은 금지됩니다.

5. 제한사항

  • GPU 보호를 위해 한 번에 1개 엔진만 실행 — 실행 엔진은 GET /tts/engines로 확인
  • 텍스트 500자 이하 · 업로드 WAV 3~30초, 10MB 이하
  • 사용자 등록 보이스는 CosyVoice 엔진에서만 동작 (Kokoro는 내장 프리셋 전용)

6. 상세 문서

전체 API 명세는 Swagger 문서에서 확인하세요.
