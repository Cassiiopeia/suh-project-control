## 개요
팰월드 서버 제어판과 유사하게, 로컬 Ollama 데몬 프로세스를 정밀 진단·소생시키고 VRAM 점유 모델들을 실시간 언로드(청소)하며, 윈도우 깊은 곳의 `server.log`를 스트리밍하는 독립 전용 "Ollama 관리" 어드민 페이지 및 백엔드 원격 구동 파워쉘 래퍼를 전격 개설합니다.

## 세부 구현 마일스톤
1. **Ollama 관리 전용 웹 탭 개설 (Flask 어드민)**
   - 왼쪽 사이드바 네비게이션 탭에 "Ollama 관리" 정식 추가 및 `GET /admin/ollama` 라우터 신설
   - **데몬 제어 카드**: 프로세스 생사 지시등, '데몬 시작/중지/재시작' 버튼 배치
   - **VRAM 관리 카드**: 현재 메모리에 로드된 활성 모델 리스트 실시간 가시화 및 'VRAM 강제 청소' 버튼 탑재
   - **실시간 로그 뷰어**: 윈도우 내부 `server.log` 최근 200줄 실시간 패치 스트리밍 뷰잉
2. **백엔드 프로세스 제어 및 로그 추적 아키텍처**
   - 윈도우즈 OS 환경에 알맞게 홈 디렉토리 명세를 런타임 추적하여 `~/.ollama/logs/server.log` 혹은 `AppData/Local/Ollama/server.log` 등 세 곳의 설치 후보 로그 경로를 자동 스캔해 유효경로 자율 바인딩
   - 윈도우 권한 제약 극복 가드: `Restart-Service -Name Ollama` 실패 시 일반 사용자 권한으로도 기동 가능한 태스크킬 방식(`taskkill /F /IM ollama.exe`) 및 백그라운드 오프라인 백그라운드 구동(`subprocess.Popen(["ollama", "serve"])`)으로의 완벽한 2중 폴백 명령 래퍼 수립
   - Command Injection 원천 방지를 위해 `shell=False` 및 단독 아규먼트 명사 배열 가드 구현
3. **벤치마크 테스트 VRAM 자동 청소 정책 연계**
   - Ollama 테스트 요청 구성 카드 상단에 **"자동 VRAM 청소 정책 (Auto Unload)" 토글 스위치(기본값: ON)** 전격 배치
   - 토글 기동 시, 자바스크립트가 개별 모델 추론 및 RDB 저장을 완료한 직후 백엔드로 `POST /ollama/control/unload` 신호를 즉각 쏘아 보내어, VRAM 점유 한도를 항상 `0%`로 순화시켜 연속 벤치마킹을 무제한으로 돌려도 절대 타임아웃 나지 않는 영구 안전 장치 연계
