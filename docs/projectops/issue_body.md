## 개요
Ollama Structured Output 테스트 대시보드에 다중 모델 벤치마크 결과를 AI 프롬프트 분석 및 사람이 읽기 편한 고품질의 마크다운 형식으로 한눈에 내보내는 원클릭 조작 컨트롤(클립보드 복사 & 파일 다운로드)을 배치하여 기능을 고도화하고, `CLAUDE.md` 가이드라인에 API Key 래퍼 사용 규약 및 브랜치 제어 수칙을 완벽히 명문화합니다.

## 세부 구현 및 개선 내용
1. **보고서 내보내기 조작 버튼 신설 (A안: 더블 소형 아이콘)**
   - 각 배치 테스트 카드 우측 상단에 클립보드 복사(`copy`) 및 마크다운 파일 다운로드(`download`) 소형 아이콘 버튼을 컴팩트하게 밀착 배치
   - 한 번의 터치로 원하는 추출 행위를 실시간 기동하도록 보증
2. **AI-Ready 및 가독성 최적화 마크다운 템플릿**
   - 벤치마크 수행 일시, 온도, 시스템 지침 및 프롬프트 기본 정보를 동적 인메모리 수집
   - 실시간 렌더링된 요약 테이블의 모든 행(정량 지표) 파싱 가공 및 각 모델이 생성한 들여쓰기된 구조화 JSON 원문 코드 펜스(` ```json `)를 정밀 조립
3. **클립보드 복사 보안 가드 및 안전 소멸 Blob 다운로드**
   - HTTPS 또는 localhost 가 아닌 비보안 IP 및 브라우저 환경에서 Clipboard API가 제한될 때 실행되는 임시 `<textarea>` 우회 셀렉션 복사 폴백(Fallback) 탑재
   - Blob 인스턴스를 통해 기기 디스크에 다운로드 시킨 뒤 즉시 `revokeObjectURL`을 기동하여 인메모리 누수 원천 제거
4. **개발 가이드라인 명문화 (`CLAUDE.md`)**
   - 프론트 API 호출 시 API Key가 자동 탑재되는 `window.apiFetch(path, options)` 의무 사용 명시
   - 모든 수정, 패치, 기능 개선 작업은 오직 `develop` 브랜치 소스 기반으로 한정 진행하는 형상 운영 수칙 제정
