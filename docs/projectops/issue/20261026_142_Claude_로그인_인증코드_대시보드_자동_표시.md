📝 현재 문제점
---

- Windows 서버(상시 가동)에서 Claude Code 로그인 시 이메일 매직링크 인증을 거쳐야 함
- 매번 Gmail 접속 > Anthropic "Claude의 보안 링크가 도착했습니다" 메일 찾기 > 로그인 버튼 클릭 > 6자리 인증 코드 확인 > 로그인 화면에 입력하는 수작업 반복
- 링크 유효시간 10분이라 메일을 늦게 찾으면 처음부터 다시 진행

🛠️ 해결 방안 / 제안 기능
---

- 관리 대시보드에 "Claude 로그인 인증 코드" 화면 추가
- 화면을 열면 서버가 Gmail 새 메일 확인 > 매직링크 추출 > 서버 브라우저로 링크 열기 > 인증 코드 읽기를 자동으로 진행
- 인증 코드를 대시보드에 크게 표시하고 복사 버튼 제공, 사용자는 로그인 화면에 붙여넣기만 하면 됨
- 인증 코드는 계정 로그인 열쇠와 같으므로 기존 관리자 로그인 뒤에만 노출

⚙️ 작업 내용
---

- Gmail 메일 읽기: chan4760@gmail.com IMAP + 앱 비밀번호(메일 읽기 전용, 서버 환경설정에만 보관)
- 대상 메일: 발신 `mail.anthropic.com`, 최근 10분 이내, 본문의 `claude.ai/magic-link#...` 링크
- 링크 열기: 서버에서 헤드리스 브라우저로 접속 > "인증 코드를 사용하여 계속하기" 화면의 6자리 코드 추출
- 대시보드 화면: 대기 중 / 메일 수신 / 코드 표시 / 시간 초과 상태 구분, 관리 작업 감사로그 기록
- 관련 위치: `suh-ai-server/flask/router/admin_router.py`, `suh-ai-server/flask/config/`, `suh-ai-server/flask/templates/`

🔍 사전 검증 결과 (2026-10-26, Mac에서 시험)
---

- IMAP 앱 비밀번호 접속 성공, Anthropic 메일 조회 확인
- Claude Code 로그인(`claude auth login`) 주소를 브라우저 A에서 열고 이메일 입력 > 메일 발송
- 시험 스크립트가 메일 수신 25초 후 링크 추출 > **다른 브라우저 프로필(헤드리스)** 에서 열기 > 6자리 인증 코드 화면 정상 표시
- 즉, 링크를 처음 로그인을 시작한 브라우저가 아닌 서버 쪽에서 열어도 코드를 받을 수 있음 (Cloudflare 차단 없음)
- 남은 확인: Windows 서버 IP에서도 동일하게 동작하는지, 받은 코드를 원래 화면에 넣었을 때 Claude Code 코드 발급까지 이어지는지
