## 개요
Ollama Structured Output 테스트 페이지(`ollama-test.html`, `ollama-test.js`)에 다중 모델 선택 기능, 순차 벤치마킹 실행 루프, 상세한 토큰 및 시간 메트릭 비교 분석 테이블 등을 도입하여 고도화합니다.

## 세부 요구사항 및 개선 내용
1. **모델 다중 선택 및 패밀리 그룹화 UI**
   - 단일 select 드롭다운에서 계열(Family)별 체크박스 다중 선택 UI로 개편
   - '전체 선택', '전체 해제' 기능 및 vision/size 등 스펙 배지 제공
2. **순차적 벤치마크 실행 흐름**
   - `for...of` 루프를 사용한 직렬식 비동기 요청 수행 (서버 메모리 보호)
   - 진행률 프로그레스 바 및 텍스트 인디케이터 제공
   - 실행 중단 제어를 위해 `AbortController` 기반 중지 기능 구현
3. **지표 요약 비교 테이블 및 상세 카드 레이아웃**
   - 각 모델의 상태, 총 처리 시간, 로드 지연(`load_duration_ms`), 추론 시간(`eval_duration_ms`), 입력 토큰 수, 출력 토큰 수, 추론 속도(tok/s)를 한눈에 대조할 수 있는 비교 테이블 동적 주입
   - 클라이언트 사이드 가벼운 JSON Schema 준수 여부 정밀 유효성 검증 마크 제공
   - 개별 상세 응답 및 메트릭 카드 시각화
4. **로컬 상태 캐싱 보존**
   - `localStorage`를 활용하여 작성 중이던 프롬프트, 온도, JSON Schema 템플릿, 선택 모델 목록 등이 새로고침 시에도 소실되지 않도록 보존
