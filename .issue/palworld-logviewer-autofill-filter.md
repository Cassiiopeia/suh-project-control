📝 현재 문제점
---

- 로그 뷰어에서 API 응답은 정상(이벤트 35줄, 감사 8줄 등)인데 화면에는 **"(필터에 맞는 로그 없음)"**만 표시되는 현상
- 원인: 검색창(`data-role="search"`)에 브라우저 **자동완성이 값("kimchi")을 채워 넣어** 모든 로그가 검색 필터로 걸러짐 (카운터 `0 / 35 줄`이 증거 — 35줄 수신, 0줄 매칭)
- 빈 결과 메시지가 **어떤 필터 때문인지 알려주지 않아** 사용자가 버그로 오인 — 원인 파악 불가

🛠️ 해결 방안
---

- 검색 입력에 `autocomplete="off"` 적용 — 브라우저 자동완성 원천 차단
- 주기 갱신 시 검색창의 실제 표시값과 활성 필터를 동기화 (자동완성이 input 이벤트 없이 채워도 화면=필터 일치 보장)
- 빈 결과 메시지에 **활성 필터를 명시**: `검색어 "kimchi" · 레벨 필터(에러)에 맞는 로그가 없습니다. 필터를 지우면 전체 로그가 표시됩니다.`
