📝 현재 문제점
---

- Claude 로그인 인증코드 화면(`/admin/claude-login`)은 서버 `.env`에 적힌 Gmail 계정 1개만 처리한다.
- Claude를 여러 계정(현재 3개)으로 쓰는데, 다른 계정의 로그인 코드는 받을 수 없다.
- 계정을 바꾸려면 서버 환경변수를 고치고 재시작해야 해서 관리자 화면에서 관리할 수 없다.

🛠️ 해결 방안 / 제안 기능
---

- 관리자 화면에서 Gmail 계정을 등록·수정·사용 중지·삭제한다 (표시 이름, 주소, 앱 비밀번호).
- 등록할 때 Gmail 접속을 먼저 시험하고 성공해야 저장한다.
- 계정 정보는 DB에 저장하고, 앱 비밀번호는 AES로 암호화한다. 암호화 키의 원본(비밀 문구)은 DB 밖 서버 설정에만 둔다. Windows에서 Mac으로 서버를 옮겨도 같은 비밀 문구로 복호화된다.
- 코드 화면은 계정마다 카드를 보여 주고, 등록된 계정을 동시에 기다려서 메일이 온 계정 카드에 6자리 코드를 띄운다. 계정별 다시 기다리기를 지원한다.
- 감사로그에 계정 추가·수정·삭제·접속 테스트와 계정별 코드 요청·발급·열람을 남긴다 (앱 비밀번호는 기록하지 않음).
