🗒️ 설명
---

- 관리 페이지 Claude 로그인 화면이 "메일을 기다리는 중"(1단계 대기)에서 멈추고 6자리 코드가 표시되지 않는다.
- Gmail 접속 테스트는 성공하고, 로그인 메일도 Gmail에 정상 도착한다 (발신 `mail.anthropic.com`, 변동 없음).
- Anthropic 로그인 메일의 링크 형식이 또 바뀌었다.
  - 처음: `claude.ai/magic-link#토큰`
  - 2026-10-31 (#144): `claude.ai/magic-link?client=...#토큰`
  - 2026-11-13 (이번): `claude.ai/magic-link/android#토큰` (경로가 추가됨)
- 링크 추출 규칙이 `magic-link` 바로 뒤에 `?` 또는 `#`만 허용해, 메일을 로그인 메일로 인식하지 못하고 10분 동안 대기한다.
- 링크를 직접 열면 기존과 같은 "인증 코드를 사용하여 계속하기" 화면에 6자리 코드가 정상 표시됨 (코드 읽기 쪽은 변경 없음).
- 형식이 바뀔 때마다 같은 장애가 반복되므로, 이번 형식만 맞추지 않고 형식 변화에 견디도록 호환성을 강화한다.
  - `magic-link` 뒤 경로·쿼리 형태와 무관하게 인식
  - Anthropic 메일인데 링크를 못 찾으면 로그로 남겨 다음 변경을 바로 파악
- 관련: #142, #144, #184
