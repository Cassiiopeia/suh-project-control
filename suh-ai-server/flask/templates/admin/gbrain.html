토큰을 만들었어요

이 토큰은 지금만 볼 수 있어요. 창을 닫으면 다시 볼 수 없으니 먼저 복사해 두세요. 잃어버리면 이 토큰을 폐기하고 새로 만들면 돼요.
토큰
방법 1. 그 컴퓨터의 터미널에 한 줄 붙여 넣기 (가장 쉬워요)
방법 2. Claude Code 설정 파일의 mcpServers 안에 직접 넣기
연결하는 순서
  1. 연결할 컴퓨터에서 터미널을 열어요.
  2. 방법 1 의 한 줄을 붙여 넣고 Enter 를 눌러요. 이미 gbrain 이 있다고 나오면 먼저 claude mcp remove gbrain -s user 를 실행하고 다시 붙여 넣어요.
  3. 열려 있는 Claude Code 를 모두 닫고 다시 열어요.
  4. Claude Code 에서 /mcp 를 입력해 gbrain 이 connected 로 보이면 끝이에요.
토큰은 비밀번호와 같아요. 메신저·메일·문서에 붙여 넣지 말고 그 컴퓨터에만 넣어 주세요.
