연결하는 순서
  1. 연결할 컴퓨터에서 터미널을 열어요.
  2. 방법 1 의 한 줄을 붙여 넣고 Enter 를 눌러요. 이미 {{ token_page_settings.personal_mcp_server_name }} 이 있다고 나오면 먼저 claude mcp remove {{ token_page_settings.personal_mcp_server_name }} -s user 를 실행하고 다시 붙여 넣어요.
  3. 열려 있는 Claude Code 를 모두 닫고 다시 열어요.
  4. Claude Code 에서 /mcp 를 입력해 {{ token_page_settings.personal_mcp_server_name }} 이 connected 로 보이면 끝이에요.
토큰은 비밀번호와 같아요. 이 기기의 Claude Code 에만 넣어 두세요.
